- Proyecto  RETO TECNICO JAVA

- Para ejecutar y verificar la salidas de datos:

- En la clase main "Application", hay datos que sirven como entrada, se pueden cambiar a decision y tambien ejecutar mediante el icono por defecto
 
 - Por medio de git bash consola puede introducir los siguientes comandos para ejecutar el jar:
   - mvn clean package
   - java -jar target/prueba-tecnica-java-1.0-SNAPSHOT-jar-with-dependencies.jar

- En el apartado de test se puede ejecutar de  forma normal para verificar sus resultados
